# NNNN: Title in the imperative

| Field | Value |
|---|---|
| Status | Proposed, Accepted, or Superseded by NNNN |
| Date | YYYY-MM-DD |
| Refs | Requirement and invariant IDs |

## Context

State the problem and the forces. Give facts, not opinions.

## Decision

State the decision in one or two sentences. Use active voice.

## Alternatives

List each alternative and the reason to reject it.

## Consequences

List what becomes easier, what becomes harder, and what is now a constraint.
